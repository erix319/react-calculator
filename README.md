## Overview

A working calculator built in React — a compact exercise in managing UI state and handling a grid of interactive controls.

## ✨ Features

- Basic arithmetic operations
- Live expression / result display
- Clear and reset
- Component-based button grid

## 🛠️ Tech stack

- **React** — Component UI and state
- **Vite** — Tooling
- **CSS** — Layout and theming

## 🎓 What it demonstrates

- `useState` for derived display state
- Event handling across a control grid
- Lifting and centralising state

## 🚀 Getting started

```bash
npm install      # install dependencies
npm run dev      # start the Vite dev server
npm run build    # production build into dist/
npm run preview  # preview the production build
```

> Requires Node.js 18+. Deployed to GitHub Pages automatically on push via GitHub Actions.
